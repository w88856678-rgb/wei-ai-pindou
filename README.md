# 为爱拼豆

把一张图片，变成可以动手制作的拼豆图纸。为爱拼豆支持在浏览器中转换图片、逐格编辑和导出图纸，让图案准备、配色调整与材料统计集中完成。

**[打开为爱拼豆](https://w88856678-rgb.github.io/wei-ai-pindou/)**

## 适合谁

- **拼豆爱好者**：把喜欢的图片整理成图纸，再按自己的想法修改细节。
- **公益手作与活动组织者**：把已获授权的公益图片做成手作图案，准备打印图纸与用量清单。
- **需要分层制作的创作者**：通过图层管理图案，并查看叠层的 3D 效果。

## 可以做什么

- **图片转图纸**：导入 PNG、JPEG 或 WebP 图片，调整尺寸、色数上限和背景处理，在本地生成可编辑图案。
- **逐格修改细节**：使用画笔、橡皮、填充和取色等工具调整图案，也可撤销与重做。
- **用图层组织作品**：新建、复制、隐藏或锁定图层，选择哪些图层计入用量统计。
- **查看 3D 效果**：旋转、缩放拼豆预览，观察图案与叠层；3D 预览需要浏览器支持 WebGL。
- **导出制作资料**：导出 PNG/PDF 图纸、Excel 用量清单，以及用于备份的 JSON 编辑记录。

## 怎么开始

1. 打开网站，导入一张有权使用的图片，设置图纸尺寸和色数。
2. 调整背景与配色，用编辑工具和图层修改细节，并查看预览。
3. 导出图纸与用量清单，准备制作；重要作品同时导出 JSON 编辑记录备份。

## 图片、草稿与兼容性

图片转换在浏览器本地完成，使用本地图像处理生成图案。生成结果需要自行检查细节、色号与用量，屏幕颜色和实际材料可能存在差异。

草稿保存在当前浏览器中，浏览器数据清理、存储限制或换设备都会影响恢复。请主动导出重要作品，不要把自动保存作为唯一备份。

**旧版 JSON 编辑记录存在兼容问题，可能导入为空图并覆盖当前浏览器草稿。** 导入前请先导出当前作品备份，保留原始文件，并检查导入结果；当前版本不承诺兼容所有历史记录格式。
